1. Rust WebAssembly Facade (OpCoreWasm)

The in-browser 3D Clinical Workstation compiles crates/op-core-wasm to wasm32-unknown-unknown and exposes a stateful #[wasm_bindgen] facade over WorkstationKernel:

Method Purpose
new OpCoreWasm()Creates an in-browser stateful O&P CAD/CAM workstation session.
load_sample(device)Generates a procedural clinical mesh ("tt", "tf", or "afo") and runs Scan QA.
upload_stl(stl_bytes)Parses binary or ASCII .stl bytes locally, repairs winding/floaters, and runs Scan QA.
rectify(recipe_json)Evaluates an .oprecipe.json string in M0 and returns rectified mesh + radial deltas.
diff_recipe(recipe_json)Computes structured revision diff JSON versus the intake baseline.
build(recipe_json, target)Compiles watertight shell, .3mf (orcaslicer / prusaslicer), CNC carver mold/G-code, safety lint, and PDF dossier.
get_artifact_bytes(filename)Returns raw binary artifact bytes (device_shell.stl, device_orcaslicer.3mf, etc.) for direct Blob download.

2. Python Command-Line Tools (op-core)

From the props repo, run via PYTHONPATH=src python3 -m op_core.cli <command>:

Command Summary & Key Flags
ui Launches the local zero-dependency WebGL 3D workstation (--host 127.0.0.1, --port 8765, --no-browser).
demo Generates a synthetic TT or AFO case and compiles all outputs (--out-dir, --device {tt,afo}, --target {orcaslicer,prusaslicer}).
qa Prunes floaters, flags tears/double walls/seam steps, aligns +Z proximal, and slices 20 mm circumferences (--out-stl, --measured-bar-mm, --expected-bar-mm).
build Compiles scan.stl + .oprecipe.json into rectified_positive.stl, device_shell.stl, device_<target>.3mf, carver_positive.stl, and device_dossier.
lint Audits any shell .stl for watertight 2-manifoldness, minimum wall thickness (--min-wall-mm 2.5), trimline smoothness, and load-axis tilt.
diff Prints a structured JSON diff between two .oprecipe.json revisions.
cam Generates GRBL/LinuxCNC 4-axis rotary foam-carver G-code (X, Z, A) and verifies ball-nose stock removal (RMS ≤ 0.5 mm, 0 gouges).
compare Rigidly registers a follow-up scan onto a baseline via 3D ICP and reports surface deviation & limb volume change (%).
gait Parses OpenCap / OpenSim .mot kinematics and GRF tables to flag asymmetry, drop-foot, and ISO 10328 peak load sizing.
doctor Probes optional accelerators (numpy, scipy, trimesh, manifold3d, ampscan) and external binaries (ccx, gmsh, blender).

4. Core Kernel Modules

Both the Python reference kernel (src/op_core/) and the Rust WebAssembly port (crates/op-core-wasm/src/) share the same modular architecture:

  • mesh & math3d — Pure triangle mesh, manifold audit, Dijkstra geodesics, binary/ASCII STL I/O, Rodrigues rotations, 3×3 Jacobi PCA, 2D convex hull, C2 quintic smoothstep.
  • scan_qa & repair — Vertex welding, consistent winding repair, hole filling, floater pruning, double-wall & seam-step detection, canonical limb alignment, 20 mm taut-tape slicing.
  • recipe & rectify — .oprecipe.json v0.1 validation, revision diffing, non-destructive M0 geodesic reliefs, sculpt strokes, Taubin smoothing, and AFO posture neutralization.
  • shell, export_3mf, carver_cam, & linter — Variable-thickness TT/TF/AFO shells, pyramid & coaxial hardware bosses, OrcaSlicer/PrusaSlicer .3mf modifier meshes, 4-axis rotary foam-carver molds & G-code, pre-print safety linter, and archival JSON/MD/PDF dossiers.

Minimal Python API Example

from op_core import OpRecipe, apply_recipe, build_tt_socket_shell, export_3mf, run_scan_qa
from op_core.synthetic import generate_transtibial_limb

case = generate_transtibial_limb(open_cuff=True, seed=0)
aligned, qa = run_scan_qa(
    case.mesh,
    mpt_point=case.landmark_coords["mpt"],
    distal_point=case.landmark_coords["distal_end"],
)
recipe = OpRecipe.load("examples/tt_socket.oprecipe.json")

rect = apply_recipe(aligned, recipe)
shell_res = build_tt_socket_shell(rect.rectified_mesh, flexion_deg=5.0, adduction_deg=5.0)
export_3mf(shell_res.shell_mesh, shell_res.modifier_mesh, "out/socket.3mf", target="orcaslicer")
