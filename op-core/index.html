op-core (props)

rust · wasm · webgl1 · o&p cad/cam GitHub repository →

op-core (from the NotGoodAtCoding/props project) is an open-source digital CAD/CAM kernel built to remove proprietary lock-in and destructive mesh editing from Orthotics & Prosthetics (O&P) workflows. The full geometry, rectification, shelling, and dual-CAM kernel is ported to pure Rust and compiled to WebAssembly (op-core-wasm) so it runs 100% locally in your browser with zero servers or patient data uploads.

Who It Is For & What It Solves

  • Practicing Clinicians (CPOs): Catch bad mobile scans chairside in seconds (qa), verify 20 mm landmark-anchored circumferences against tape measurements, and record unambiguous check-socket revisions in portable .oprecipe.json files.
  • O&P Technicians & Central Labs: Apply non-destructive socket and AFO rectifications in the undeformed reference domain M0 without topology drift, export watertight shells (STL + slicer-targeted .3mf reinforcement modifiers) or CNC foam-carver molds & 4-axis G-code, and auto-generate custom-device traceability dossiers.
  • Biomedical & CAD Engineers: Run deterministic, zero-dependency geometry pipelines in Python or pure-Rust WebAssembly without Blender (bpy), VTK, or OpenVDB installation friction.

End-to-End Pipeline

  Raw Scan (.stl)
        │
        ▼
  [ 1. Scan QA ] ─────────► Prune floaters, flag double walls / seam steps / tears,
        │                   align +Z proximal, slice 20 mm MPT circumferences
        ▼
  [ 2. .oprecipe.json ] ──► Non-destructive liner offset, compression, reliefs,
        │                   & AFO ankle posture evaluated in reference domain M_0
        ▼
  [ 3. Compile & Export ] ┬─► device_shell.stl        (watertight, MPT/AFO aligned)
                          ├─► device_<slicer>.3mf     (100% distal/neck modifiers)
                          ├─► carver_positive.stl     (keyed mandrel + 12° collar)
                          ├─► carver_4axis.gcode      (GRBL/LinuxCNC rotary toolpath)
                          └─► device_dossier.json/md/pdf (safety lint + audit log)
