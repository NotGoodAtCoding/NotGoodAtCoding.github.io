Getting Started with op-core

← op-core overview launch workstation .oprecipe schema CLI & API reference GitHub →

Who this page is for: Practicing O&P clinicians (CPOs), fabrication technicians, and developers running op-core for the first time—either directly in the browser via Rust/WASM or locally via the Python CLI.

1. Zero-Install Browser Workstation (Rust + WASM)

The fastest way to try the full 5-step clinical workflow is the in-browser 3D Clinical Workstation, powered by op-core-wasm (zero installs, zero uploads—all STL files stay on your device):

  1. Step 1 — Scan QA: Click Sample TT, Sample TF, Sample AFO, or upload any patient .stl scan (in mm) to inspect PASS/WARN/FAIL QA checks and 20 mm taut-tape slices.
  2. Step 2 — Landmarks: Click Pick on 3D Mesh, then click directly on the 3D limb surface to snap landmarks (pt_bar, fibular_head, tibial_crest, etc.).
  3. Step 3 — Rectify: Adjust non-destructive M0 sliders (or paint sculpt strokes) and preview the radial delta heatmap—compression in blue, relief build-up in amber/red.
  4. Step 4 — Shell & Lint: Tune wall thickness and bench alignment (flexion, adduction, or AFO trimline fillet), then click Compile Shell, .3MF & Carver.
  5. Step 5 — Export: Download device_shell.stl, device_<slicer>.3mf, carver_positive.stl, 4-axis G-code, .oprecipe.json, and traceability dossiers (.json/.md/.pdf).

2. Local Python CLI Setup (Zero External Dependencies)

Clone NotGoodAtCoding/props. The MVP core runs directly on Python 3.11 / 3.12+ using only the Python standard library: 

# Launch the local 3D browser UI
PYTHONPATH=src python3 -m op_core.cli ui --port 8765

# Or install editable so `op-core` is directly on your PATH
pip install -e .
op-core --help

3. 30-Second Offline CLI Demo

Without a patient .stl on hand, demo generates a synthetic transtibial (TT) residual limb or plantarflexed Ankle-Foot Orthosis (AFO) scan and executes the complete CAD/CAM pipeline: 

# Transtibial socket demo (OrcaSlicer .3mf + CNC carver mold + dossier)
PYTHONPATH=src python3 -m op_core.cli demo --out-dir ./demo_tt --device tt --target orcaslicer

# Ankle-Foot Orthosis (AFO) demo (ankle neutralization + sole flattening + coaxial joints)
PYTHONPATH=src python3 -m op_core.cli demo --out-dir ./demo_afo --device afo --target prusaslicer

4. Chairside Scan QA (op-core qa)

Validate any binary or ASCII .stl scan before spending fabrication time on a corrupted file: 

PYTHONPATH=src python3 -m op_core.cli qa ./demo_tt/sample_scan.stl --out-stl ./demo_tt/aligned.stl
  • floater_components_removed — Detached background/table fragments automatically pruned.
  • proximal_cuff_loops vs. internal_tear_loops — Verifies the open proximal cuff is intact and flags unintended scanning holes (FAIL).
  • double_wall_vertices — Flags overlapping SLAM tracking surfaces (FAIL if > 15 stacked vertices).
  • seam_step_score_mm — Flags sharp loop-closure ridge steps (FAIL if > 1.0 mm).
  • detected_scale_ratio — With --measured-bar-mm / --expected-bar-mm, flags scale drift exceeding ±2.0%.
  • slices — Convex-hull taut-tape circumferences measured every 20 mm downward from the Mid-Patellar Tendon (MPT) plane.

5. Compile & Revise a Check-Socket Recipe (build + diff)

PYTHONPATH=src python3 -m op_core.cli build \
  ./demo_tt/sample_scan.stl \
  examples/tt_socket.oprecipe.json \
  --out-dir ./build_v1 \
  --target orcaslicer

PYTHONPATH=src python3 -m op_core.cli diff \
  examples/tt_socket.oprecipe.json \
  examples/tt_socket_v2.oprecipe.json

Because op-core evaluates every relief in the undeformed reference mesh domain M0, relaxing global compression in a v2 check-socket revision will not distort or shift surrounding anatomical reliefs.
