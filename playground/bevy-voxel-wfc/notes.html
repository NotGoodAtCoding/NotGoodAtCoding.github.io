3D Voxel Wave Function Collapse — Architecture & Code Notes

rust · bevy 0.18 · wfc · priority-flood · voxel ao ← open live diorama

Naive 3D Wave Function Collapse with four raw states (Land, Foliage, Water, Air) quickly produces floating dirt chunks, spilling water cubes, and disconnected leaf blobs. This playground solves all three on a 20×20×20 (8,000-cell) grid by expanding those four user-facing categories into 15 bitmask states and running three deterministic passes seeded from a single user string.

1. Compact u16 Bitmask Domains & Symmetric Adjacency

Each of the 8,000 cells stores its superposition of still-valid tiles as a single u16 bitmask—only 16 KB for the entire 3D grid. A cell is collapsed when mask & (mask - 1) == 0 (power of two), and a contradiction occurs when mask == 0.

Category Internal WFC States (15 bits) Structural Invariant
Land DeepRock, Subsoil, Grass, CliffRock Grounded to y = 0 (no land above Air or Water); steep drops force CliffRock
Water Water Flat sea table at y ≤ y_sea in Pass 1 + enclosed highland basins in Pass 2
Foliage Bush, TrunkBase, TrunkMid, CanopyCore, Leaf±X/±Z/Top Roots strictly on arable Grass; directed leaf sockets guarantee complete crowns
Air Air Pre-collapsed on y = 19; forbidden below sea level

Every adjacency rule is registered through a single symmetric helper so B ∈ allowed[A][d] ⇔ A ∈ allowed[B][−d] holds by construction. During propagation, computing the union of allowed neighbor tiles walks only the set bits of a cell's domain using Kernighan's bit-clearing trick: 

// crates/bevy-voxel-wfc/src/wfc.rs
fn allow_directed(&mut self, a: Tile, dir: Dir, b: Tile) {
    self.allowed[a as usize][dir as usize] |= b.bit();
    self.allowed[b as usize][dir.opposite() as usize] |= a.bit();
}

pub fn support_mask(&self, mut mask: u16, dir: Dir) -> u16 {
    let mut union = 0u16;
    let dir_idx = dir as usize;
    while mask != 0 {
        let tz = mask.trailing_zeros() as usize;
        union |= self.allowed[tz][dir_idx];
        mask &= mask - 1; // clear lowest set bit
    }
    union
}

2. Shannon Entropy, AC-3 Propagation & Undo-Trail Rollback

At each step, the solver picks the uncollapsed cell with the lowest weighted Shannon entropy plus a tiny per-cell deterministic tiebreaker ε:

H(c) = ln(Σ wi) − (Σ wi ln wi) / (Σ wi) + εc

Because speculative collapses can occasionally dead-end inside 3D constraints, copying the entire 8,000-cell array on every trial would waste memory bandwidth. Instead, try_collapse records every narrowed cell onto a lightweight undo_trail: Vec<(usize, u16)> so failed branches unwind in exact reverse order in microseconds, while a small checkpoint stack (saved every 128 collapses) recovers from deeper contradictions: 

// Pseudocode for WfcSolver::step_pass1_once & try_collapse (wfc.rs)
target = argmin over uncollapsed cells of (cached_entropy[c] + tiebreak[c])
domain = cells[target]

while domain != 0:
    chosen = weighted_sample(rng, domain, pass1_weight(field, x, y, z))
    undo_trail.clear()
    push (target, cells[target]) onto undo_trail
    cells[target] = chosen.bit()

    if propagate_ac3_recording_undo(target):
        update cached_entropy for cells touched in undo_trail
        if collapsed >= last_checkpoint + 128: save_checkpoint()
        return Ok
    else:
        for (idx, prev_mask) in undo_trail.rev():
            cells[idx] = prev_mask          // zero-allocation rollback
        domain &= !chosen.bit()             // ban failed candidate

// All local candidates contradicted -> pop checkpoint, or restart Pass 1 with next retry seed
if let Some(cp) = checkpoints.pop(): restore(cp)
else: init_pass1(pass_retries + 1)

3. Grounded Land, Automatic Steep Cliffs & Flat Sea Level

Three simple domain rules enforce realistic macro geology without any post-hoc terrain patching:

  • Zero floating land (by induction): y = 0 is pre-collapsed to DeepRock, and no land tile lists Air or Water as a valid -Y neighbor. Every solid voxel is guaranteed to sit on an unbroken solid column down to the base.
  • Emergent cliff rock on steep drops: Grass may face Air horizontally, so a gentle 1-voxel hill keeps lush green turf while its Subsoil underneath touches the neighboring column's Grass. On a 2+ voxel drop, however, Subsoil and DeepRock forbid Air horizontally—forcing AC-3 propagation to collapse the exposed sheer face into CliffRock. Above y ≥ 14, Grass weight drops to zero so alpine peaks cap cleanly in rock.
  • Flat sea-level water table: Before Pass 1 starts, Water is masked out above y_sea and Air is masked out at or below y_sea. Any terrain valley dipping below sea level fills dead-flat inside WFC itself, and because Grass forbids Water above, submerged beds automatically collapse into Subsoil or rock.

4. Elevated Enclosed Mountain Ponds (Barnes Priority-Flood)

Hydrostatic containment above sea level is a global property—a mountain bowl can only hold water if a closed rim higher than its floor surrounds it on all paths to the diorama's outer edge. Pass 2 computes each column's exact spill height in O(N log N) using a min-heap seeded from the four perimeter walls: 

// crates/bevy-voxel-wfc/src/wfc.rs (Pass 2: Barnes Priority-Flood)
// Seed min-heap with the 4 diorama perimeter edges (clamped up to y_sea).
for (x, z) on perimeter:
    spill[x][z] = surface[x][z].max(y_sea)
    heap.push(Reverse((spill[x][z], x, z)))

while let Some(Reverse((h, x, z))) = heap.pop() {
    for (nx, nz) in four_neighbors(x, z) {
        if !visited[nx][nz] {
            visited[nx][nz] = true;
            let nh = surface[nx][nz].max(h);
            spill[nx][nz] = nh;
            heap.push(Reverse((nh, nx, nz)));
        }
    }
}

// Fill interior enclosed bowls strictly above sea level, sorted bottom-up for animation.
for x in 1..(GRID_SIZE - 1), z in 1..(GRID_SIZE - 1):
    if spill[x][z] > surface[x][z] && spill[x][z] > y_sea + 1 {
        for y in (surface[x][z] + 1).max(y_sea + 1)..=spill[x][z] {
            queue_pond_water(x, y, z); // also converts submerged Grass -> Subsoil
        }
    }

Because every perimeter edge drains out, no elevated pond voxel can ever hang off the side of the 20×20 cube or touch Air horizontally. Sorting the queued pond voxels by y lets animated mode visibly fill mountain basins layer by layer.

5. Zero-Orphan Trees via Directed Canopy Sockets (Pass 3)

In pairwise 6-neighbor WFC, a single generic CanopyLeaf tile that permits Air on all sides will happily spawn floating leaf cubes in midair. Pass 3 solves this cleanly by locking Pass 1–2 terrain and introducing five directed leaf socket tiles (LeafPosX, LeafNegX, LeafPosZ, LeafNegZ, LeafTop): 

// crates/bevy-voxel-wfc/src/wfc.rs
// Bidirectional socket locks: a LeafPosX tile MUST sit immediately +X of a CanopyCore!
table.allow_directed(Tile::CanopyCore, Dir::PosX, Tile::LeafPosX);
table.allow_directed(Tile::CanopyCore, Dir::NegX, Tile::LeafNegX);
table.allow_directed(Tile::CanopyCore, Dir::PosZ, Tile::LeafPosZ);
table.allow_directed(Tile::CanopyCore, Dir::NegZ, Tile::LeafNegZ);
table.allow_vertical(Tile::CanopyCore, Tile::LeafTop);

// Outer horizontal faces of leaves may touch Air, terrain, or another tree's outer leaf,
// as long as neither touching face is a CanopyCore socket.
for &leaf in &Tile::LEAVES {
    for dir in Dir::HORIZONTAL {
        if Some(dir) == leaf.leaf_core_dir() { continue; }
        for &other in &Tile::LEAVES {
            if Some(dir.opposite()) != other.leaf_core_dir() {
                table.allow_directed(leaf, dir, other);
            }
        }
    }
}

Combined with TrunkBase requiring Grass below and TrunkMid | CanopyCore above (while forbidding adjacent trunks), every tree automatically sprouts strictly on arable meadow grass with guaranteed headroom, natural spacing, and zero half-built crowns or floating leaves.

6. Baked Voxel Ambient Occlusion & Zero-Framework HTML Bridge

The custom mesher emits only exposed faces bordering Air, Water, uncollapsed space, or diorama walls. Each vertex samples three coplanar neighbor voxels (side1, side2, corner) to bake classic 4-level voxel Ambient Occlusion:

ao = 0  if (side1 ∧ side2)  else  3 − (side1 + side2 + corner)

To avoid diagonal shading creases caused by Gouraud interpolation across mismatched quad triangles, each quad chooses its split diagonal along the brighter corner pair: 

// crates/bevy-voxel-wfc/src/mesher.rs
if ao_levels[0] + ao_levels[2] > ao_levels[1] + ao_levels[3] {
    indices.extend_from_slice(&[v0, v1, v2, v0, v2, v3]);
} else {
    indices.extend_from_slice(&[v1, v2, v3, v1, v3, v0]);
}

Finally, the raw HTML seed controls outside the canvas communicate with Bevy through a tiny Mutex<VecDeque<BridgeCmd>> queue exported via #[wasm_bindgen] (wfc_set_seed, wfc_set_animate, wfc_finish_now, wfc_get_seed) that a Bevy Update system drains each frame—zero JS frameworks, zero state duplication.
